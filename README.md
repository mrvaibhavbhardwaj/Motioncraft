
## Run Locally

**Prerequisites:**  Node.js
<img width="1919" height="1086" alt="image" src="https://github.com/user-attachments/assets/9f5fe65c-5a45-426c-8774-73be00b4cd8c" />


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
